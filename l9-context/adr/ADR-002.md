# ADR-002: Bounded bidirectional loops and exact-base context deltas

**Repository:** Quantum-L9/l9-context  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_DIRECTION_WITH_PROPOSED_EXECUTION_CONTRACT  
**Implementation/deployment:** not performed by this delivery.

## Context
Continuous full retrieval wastes work, while unbounded self-triggering creates recursive amplification.

## Decision
Refresh only from new authorized evidence/revision, use exact-base deltas and work-epoch budgets. Reverse ingest requests remain scoped and separately authorized.

## Alternatives not selected
Infinite same-root HTTP chain; self-corroboration of generated summaries; permission-widening discovery crawler.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Causal dedupe and revocation-aware cache identity are mandatory.

## Required evidence
Unchanged input terminates, revoked scope removes cached content and wrong delta base fails. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Stop refresh loop and retain last lawful bounded view; never reset budget to continue.

User bidirectional/circular leverage intent; global invariants L9-018/L9-022. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
