# ADR-001: Thin Gate node over existing memory domain

**Repository:** Quantum-L9/l9-memory  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_OPERATOR_DECISION  
**Implementation/deployment:** not performed by this delivery.

## Context
A new universal node is needed, but canonical memory already has an owner.

## Decision
Compose l9-graphiti-memory public facade and preserve MemoryService, canonical RecordStore and optional Graphiti projections.

## Alternatives not selected
Reimplement admission/retention in wrapper; move memory into State/Evidence; call Graphiti directly from consumers.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Wrapper only maps authenticated scope and owner request/receipt; gaps return to existing owner.

## Required evidence
Gate versus public SDK parity, consent/refusal/deletion and projection outage tests. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Disable new exposure without deleting canonical memory or reactivating unsafe direct provider writes.

## Provenance
Existing memory architecture/source baselines and user lock. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
