# ADR-003: Durable intent before effects and uncertain-outcome reconciliation

**Repository:** Quantum-L9/L9-AgentOS  
**Date:** 2026-09-25  
**Status in pack:** PROPOSED_IMPLEMENTATION_OF_LOCKED_INVARIANT  
**Implementation/deployment:** not performed by this delivery.

## Context
A worker can die after an effect but before receiving its acknowledgment.

## Decision
Commit ActionIntent and operation key before dispatch; recover by exact owner receipt. Unknown effect is reconciliation-required. Use fencing and current authorization for new attempts.

## Alternatives not selected
Retry on timeout with a fresh key; infer success from logs; treat command exit zero as universal completion.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Long-running work needs explicit pending/unknown/cancel-requested states and operator-safe recovery.

## Required evidence
Crash before send, after effect and before receipt; never duplicate external execution. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Preserve uncertain state and query owner; rollback cannot undo unknown real-world effects.

Uploaded technical-controller crash/dispatch law; global invariants L9-016/L9-019. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
