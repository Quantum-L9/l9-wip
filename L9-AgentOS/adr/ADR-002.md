# ADR-002: Autonomy evaluates attempts, not world authority

**Repository:** Quantum-L9/L9-AgentOS  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_OPERATOR_DECISION  
**Implementation/deployment:** not performed by this delivery.

## Context
State changes should make authorized work eligible without making the persistence layer an executive.

## Decision
Generic AgentOS evaluator interprets bounded AutonomyProfile under current context, state, grants and budget. Destination authority is independently enforced. Intent digest and approval bind exact request.

## Alternatives not selected
Put autonomy in Mongo triggers, provider adapters, Gate routing or an agent-specific code branch.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
AgentOS can return deny/defer/need-context without external effect; granting an attempt cannot satisfy a missing domain mandate.

## Required evidence
Expired approval, changed payload/profile and stale fence all block effect. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Suspend new attempts and reconcile existing intents; do not erase prior receipts.

User autonomy/profile locks; Cursor donor thin-adapter law. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
