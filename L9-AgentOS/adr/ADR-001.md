# ADR-001: One runtime, first-class AgentProfile and universal Work Item

**Repository:** Quantum-L9/L9-AgentOS  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_OPERATOR_DECISION  
**Implementation/deployment:** not performed by this delivery.

## Context
User converged multiple experimental agents into one substrate and explicitly unified the vocabulary.

## Decision
AgentOS consumes a compiled complete declarative AgentProfile. All work is WorkItem with profile-owned kinds, not separate architecture types. Manifestation/replica/principal identities remain separate.

## Alternatives not selected
Keep separate agent runtimes; infer agent type from its name; use one giant config file as the architecture.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
A new domain is a profile change, not core branching. Compiler/source provenance and cross-profile conformance become release obligations.

## Required evidence
Five named and unseen synthetic profiles compile and run through identical runtime interfaces. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Revert a defective profile release without changing existing Work Item binding or losing durable state.

## Provenance
User locked identity equation and AgentProfile invariant; 01_authority/LOCKED_INTENT.md. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
