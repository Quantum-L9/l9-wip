# Probabilistic Reasoning Origin

This pack extends the L9 Reasoning Plane after the architecture converged on a third sibling for uncertainty.

Locked conceptual sequence:

```text
Formal filters the impossible.
Probabilistic estimates the uncertain.
Numerical selects the valuable.
```

Probabilistic Reasoning is intentionally not named Bayesian Reasoning because Bayes is a method family beneath a provider-neutral reasoning contract.

The implementation detail in v1.1 is new relative to the v1.0 Reasoning Plane pack. The prior pack defined Formal/Numerical sibling architecture and bounded loop semantics; this pack consolidates that architecture and adds the probabilistic sibling contracts, implementation filetree, exact-reference provider plan, fixtures and provider conformance gates.
