# Signal Leverage Bridge Origin

The external Signal Leverage kernel establishes that useful evidence must preserve meaning, provenance, context, authority and uncertainty; signal topology must be earned; duplicates are not multiplied evidence; closed loops require changed future behavior; and signal loops are bounded.

The Reasoning Plane consumes these semantics without taking ownership of propagation.

Derived bridge:

```text
Observation
 -> Signal Leverage
 -> Evidence Admission
 -> Probabilistic hidden-state update
 -> Strategic Interaction
 -> Numerical Strategic Value
 -> Action
 -> new Observation
```

Important refinement: more signals do not automatically increase certainty. Redundant/correlated signals can create false confidence. A contradictory signal can make the posterior less certain while improving calibration.
