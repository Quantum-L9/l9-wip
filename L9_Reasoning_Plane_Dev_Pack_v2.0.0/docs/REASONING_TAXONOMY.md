# Reasoning Taxonomy

## Formal Reasoning
Semantic claim: admissibility / consequence under admitted facts and laws.

## Probabilistic Reasoning
Semantic claim: belief under uncertainty and admitted probabilistic model/evidence.

## Numerical Reasoning
Semantic claim: quantitative value/preference under declared objective.

## Strategic Interaction Reasoning
Not a sibling. A composed pattern coupling the triplet across strategic actors and time.

## General meta-decision reasoning
Not a sibling. A composed pattern evaluating ACT/LEARN/COMPUTE/WAIT/STOP candidates.

## Future sibling admission test
A proposed sibling must own a distinct semantic claim, resist faithful composition from existing families, expose a stable provider-neutral contract, fail/degrade independently, have real recurring consumers, and reduce more complexity than it adds.

See `REASONING_METHOD_TAXONOMY.md` for family → method family → algorithm → primitive → provider vocabulary.
