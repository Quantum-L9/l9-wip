# Canonical Composed Questions

These are reusable questions the triplet can compose to answer. They are not new nodes.

1. **Should I act?** — compare action against non-action/baseline.
2. **Should I learn?** — information value / best evidence-acquisition action.
3. **Should I compute more?** — Value of Computation / stop condition.
4. **Should I wait?** — timing value under state evolution and delay cost.
5. **Should I commit or preserve optionality?** — commitment/reversibility tradeoff.
6. **How should scarce resources be allocated?** — constrained portfolio/allocation optimization.
7. **Which intervention creates the greatest Systemic Future Value?** — compare counterfactual future trajectories.
8. **What could change the current decision?** — decision-boundary analysis.
9. **How will another actor respond?** — strategic response distribution.
10. **What is my best response?** — conditional strategic optimization.
11. **Is my policy exploitable?** — regret/exploitability under an explicit actor model.
12. **What information should I acquire?** — VOI across LEARN actions.
13. **What information should I reveal or withhold?** — strategic disclosure value subject to policy/ethics/authorization.
14. **Is this signal/threat/commitment credible?** — incentive-conditioned inference.
15. **Should I move first or wait?** — sequential strategic timing.
16. **What present strategy has highest expected Strategic Value across a bounded action/reaction horizon?** — Strategic Lookahead.
17. **What rules or incentives make desired behavior individually rational?** — mechanism-design question, future method surface.

A new composed question earns canonical status when it recurs across consumers and can be represented without assigning a new semantic owner.
