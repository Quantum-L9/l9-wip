# Failure and Degradation

The triplet degrades independently and composed patterns never authorize semantic impersonation.

## Formal unavailable

Probabilistic/Numerical cannot reinterpret hard gates as probability or utility penalties unless an independent authoritative feasible-region source exists.

## Probabilistic unavailable

Numerical cannot fabricate probabilities or treat uncertainty as certainty. Deterministic-only numerical evaluation is allowed only when the DecisionModel explicitly supports the available inputs.

## Numerical unavailable

Formal feasibility and Probabilistic belief analysis remain usable, but no value/optimization recommendation is fabricated.

## Graph Memory unavailable

Odoo/domain operation remains available. ActorModel-dependent reasoning degrades to authoritative facts and explicitly marks missing actor/context state. It does not invent a default interaction profile.

## Strategic model unavailable

A consumer may fall back to non-strategic decision evaluation only when that downgrade is explicitly allowed and another actor's adaptive response is not a hard requirement of correctness.

## Signal bridge degraded

Loss of provenance/context/uncertainty from a signal may make it inadmissible or lower-confidence evidence. The plane must not reconstruct missing provenance from guesswork.

## Typed probabilistic degradation

- `INSUFFICIENT_EVIDENCE`
- `INSUFFICIENT_MODEL`
- `INVALID_PRIOR`
- `UNSUPPORTED_MODEL`
- `DIAGNOSTIC_FAILURE`
- `BUDGET_EXHAUSTED`
- `DEGRADED_PROVIDER`

No failure path synthesizes a uniform prior, zero probability, mean-value imputation, default actor type, or fake confidence.
