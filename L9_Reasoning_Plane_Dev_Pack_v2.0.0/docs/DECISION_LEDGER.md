# Decision Ledger

## Locked

- Reasoning Plane is a semantic contract plane, not runtime aggregator.
- Current siblings: Formal / Probabilistic / Numerical.
- Semantic claims: admissibility / belief / utility.
- Consumers remain outside the plane and own orchestration/action authority.
- Einesium is historical lineage; Numerical Reasoning is canonical identity.
- Bayesian inference is a Probabilistic method family.
- No hidden priors, no hidden evidence acquisition, no probability-to-truth promotion.
- Exact probabilistic reference provider precedes approximate provider selection.
- MetaAction vocabulary: ACT / LEARN / COMPUTE / WAIT / STOP.
- State is time-indexed; material change may require re-evaluation.
- Signal meaning is context-conditioned; duplicates/correlated observations do not multiply evidence.
- Strategic Interaction is a triplet composition, not fourth sibling.
- Game theory is a method family; BoundedStrategicLookahead is an algorithm family.
- Higher-order beliefs use explicit bounded belief depth.
- ActorModel is versioned derived belief state, not person/company truth.
- Graph Memory stores dense contextual/relational actor learning; Odoo retains business truth plus optional compressed human projection.
- StrategicReasoningAdapter is a pure shared consumer adapter, not a node or orchestrator.
- Machine value vocabulary: StrategicValue / SystemicFutureValue; no undefined scalar future-value score.
- Future systemic effects use counterfactual trajectories, topology, attribution, recurrence/decay and convergence.
- Future work elimination is first-class value.
- Signal Leverage remains external signal-topology owner.
- ML is not required for v2 reference implementation.

## Explicitly rejected

- `BayesianReasoningNode` as provider/method-named architecture;
- `GameTheoryNode` or `StrategicInteractionNode` without a new semantic owner;
- probabilistic inference hidden inside Numerical Reasoning;
- scalar confidence as complete belief contract;
- uniform-prior fallback;
- probability threshold as automatic formal truth;
- direct sibling orchestration;
- plane-level workflow state or action execution;
- dense ActorModel duplication into hidden Odoo fields;
- Graph Memory as business truth;
- static rule `signal X = meaning Y` without context;
- unlimited “I think that you think...” recursion;
- unlimited game-tree lookahead;
- undefined machine-facing future-value/leverage score;
- summing overlapping future effect labels;
- cycles counted repeatedly without new state delta.
