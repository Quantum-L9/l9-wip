# Reasoning Triad Overlay

The runtime reasoning triplet is Formal, Probabilistic, Numerical. The external architecture/judgment kernels such as First-Order, Second-Order, and the historically named Leverage kernel remain outside the plane runtime.

## First-Order

Identifies governing intervention, assumptions, first-principles objective and work expected to become unnecessary.

## Second-Order

Predicts/observes consequence paths, state changes, feedback and forecast error.

## Strategic Value bridge

The Reasoning Plane does not copy a generic external rank/score into numerical code. Evidence from architecture/judgment kernels may be projected as explicit future state effects with provenance. Numerical Reasoning then values those effects using `SystemicFutureValueProjection` and compatible utility units.

```text
Intervention
 -> consequence evidence
 -> explicit future state effects
 -> SystemicFutureValueProjection
 -> Numerical SystemicFutureValue
 -> StrategicValue
```

The proper-named external **Signal Leverage** kernel remains a separate signal-topology owner and is bridged through admitted evidence/receipts, not reimplemented here.
