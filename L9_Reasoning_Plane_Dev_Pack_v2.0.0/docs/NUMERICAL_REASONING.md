# Numerical Reasoning Node

## Mission

Deterministically evaluate declared quantitative decision models over admitted state, beliefs, constraints, parameters and objectives. Numerical Reasoning owns utility/value computation, not domain meaning or action authority.

## Historical lineage

`Einesium` is the historical codename/implementation lineage. Canonical architecture identity is `L9 Numerical Reasoning`. `einsum` and similar tensor operations remain primitives/providers beneath stable semantics.

## Core method families

- Decision Evaluation
- Optimization
- Sensitivity Analysis
- Frontier Analysis
- Information Value Analysis: EVPI / EVSI / Net VOI / sequential VOI
- Computation Value Analysis
- Timing / Delay Value Analysis
- Option / Reversibility Value Analysis
- Resource Allocation Optimization
- Decision Boundary Analysis
- Strategic Value Analysis
- Systemic Future Value Analysis
- Game-theoretic numerical methods used by Strategic Interaction Reasoning

## Strategic Value

```text
StrategicValue(a)
= ImmediateExpectedValue(a)
+ SystemicFutureValue(a)
- DirectCost(a)
- ExpectedRiskLoss(a)
- OpportunityCost(a)
```

Numerical Reasoning values an explicit `SystemicFutureValueProjection`. It does not invent unsupported future effects or silently count the same state delta twice.

## Strategic interaction

Numerical Reasoning may compute best responses, payoffs, regret/exploitability, bounded action-tree value, equilibrium candidates, bargaining value, disclosure value and mechanism-design objectives under explicit Strategic Interaction contracts. These methods do not make Strategic Interaction a fourth sibling.

## Provider model

DecisionModel / NumericalExecution semantics remain stable across replaceable providers. Validation/oracle results are evidence, not authorization.

## Unknown-input law

Required unknown inputs do not silently become zero, false, uniform, average, fabricated probabilities, or default strategy weights. The DecisionModel declares missing/unknown semantics or execution fails/degrades explicitly.
