# Resource Allocation

## Cardinal question

> Given scarce resources and uncertainty, what allocation across admissible opportunities maximizes declared Strategic Value while preserving required reserves/options?

Output may be a vector or frontier rather than a single winner, e.g. `40% X / 35% Y / 15% Z / 10% reserve optionality`.

Resources may include money, compute, tokens, human attention, engineering time, inventory, machine capacity, sales effort, research budget or agent concurrency.

Formal supplies hard allocation constraints; Probabilistic supplies outcome distributions; Numerical solves the allocation objective. The consumer owns the resource semantics and actual allocation authority.
