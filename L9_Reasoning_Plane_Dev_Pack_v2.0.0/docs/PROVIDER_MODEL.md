# Provider Model

## Constitutional rule

Reasoning family identity is semantic. Method/algorithm/provider identity is implementation.

## Formal

`FormalReasoningAdapter` with Clingo + Clorm as locked first implementation.

## Probabilistic

`ProbabilisticReasoningAdapter` with `ExactReferenceProvider` proving finite-hypothesis Bayes, Beta-Binomial and Dirichlet-Categorical semantics. Production approximate provider remains deferred.

## Numerical

Replaceable execution/optimization providers and independent reference/oracle validation. Historical Einesium provider mechanics remain below the Numerical Reasoning contract.

## Strategic interaction

No new provider abstraction is required merely because game-theoretic methods are used. `StrategicReasoningAdapter` is a consumer-side compiler/joiner, while game-theoretic algorithms/providers remain behind the existing Probabilistic/Numerical boundaries or future explicitly versioned method extensions.
