# Fact, Belief, Strategic Model, and Value Admission

The plane handles different semantic currencies that must never be silently converted.

## Fact / admissibility

Formal Reasoning operates on admitted facts/laws. Memory, inferred ActorModels, probabilities and numerical outputs are not automatically facts.

## Belief

Probabilistic Reasoning operates on explicit models, priors/prior state and admitted evidence. Probability is belief evidence, not formal truth.

## Strategic model

ActorModel, StrategyHypothesis, ResponseModel and HigherOrderBelief are explicit model/hypothesis surfaces. They may be useful, calibrated and highly predictive while remaining non-authoritative beliefs about another actor.

## Value

Numerical Reasoning operates on a declared DecisionModel/objective, compatible quantitative context, constraints, parameters and optional BeliefState/strategic projections. High StrategicValue is not authority to act.

## Explicit promotion

```text
fact/admissibility != belief != actor/strategy hypothesis != utility != authority
```

Any promotion into a stronger semantic class requires the owning system's explicit admission contract.
