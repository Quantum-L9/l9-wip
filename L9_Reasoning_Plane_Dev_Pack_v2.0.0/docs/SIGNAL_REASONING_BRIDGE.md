# Signal Leverage ↔ Reasoning Plane Bridge

Signal Leverage is external to the Reasoning Plane. It owns evidence-bearing signal propagation, topology, meaning preservation, eligibility, reconvergence, evidence-bound write-back, and bounded signal loops. The Reasoning Plane does not duplicate those responsibilities.

## Canonical chain

```text
OBSERVATION
    ↓
SIGNAL LEVERAGE
preserve + route useful meaning
    ↓
EVIDENCE ADMISSION
relevant / trustworthy / eligible?
    ↓
PROBABILISTIC REASONING
update hidden-state probabilities
    ↓
STRATEGIC INTERACTION
what actor state/strategy now looks plausible?
    ↓
NUMERICAL REASONING
what action has highest Strategic Value?
    ↓
ACTION
    ↓
NEW OBSERVATIONS
    ↺
```

## Ownership

Signal Leverage owns movement, topology, preservation, eligibility and write-back discipline. It does not infer hidden state or choose intervention.

Probabilistic Reasoning owns what admitted evidence implies for belief.

Strategic Interaction Reasoning composes actor incentives, beliefs and response hypotheses.

Numerical Reasoning values candidate actions.

## Signal opportunity states

Distinguish:
1. `UNOBSERVED` — signal existed but was not perceived;
2. `OBSERVED_UNRECOGNIZED` — perceived but not recognized as relevant;
3. `RECOGNIZED_UNROUTED` — recognized but failed to reach an eligible consumer;
4. `ROUTED_DEGRADED` — arrived with lost context/provenance/uncertainty;
5. `ADMITTED_UNUSED` — admitted but did not reach decision consumption;
6. `REALIZED` — materially changed belief, decision, capability, cost, or future behavior.

## Metrics

`SignalCaptureEfficiency` and `SignalRealizationRate` are useful estimated operational metrics, but denominators may be partially unknowable. They must carry measurement methodology and uncertainty.

- Capture efficiency: estimated decision-relevant signal value captured / estimated decision-relevant signal value available.
- Realization rate: admitted useful signals that changed future behavior / admitted useful signals received.

Storage without future consumption is not learning.
