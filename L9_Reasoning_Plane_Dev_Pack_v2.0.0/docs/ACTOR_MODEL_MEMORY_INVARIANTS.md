# Actor Model and Memory Invariants

**AM-001** ActorModel is derived belief state, not authoritative identity or personality truth.

**AM-002** ActorModel variables are context-scoped and may overlap; do not collapse them into a single categorical opponent type.

**AM-003** ActorObservation is immutable evidence; ActorModel is a versioned inference over observations.

**AM-004** New outcomes may reinforce, weaken, broaden, narrow, or contradict an ActorModel.

**AM-005** Graph Memory may retain relational/temporal hypothesis state but never becomes authoritative commercial truth.

**AM-006** Odoo owns authoritative commercial facts/events and may expose a concise human-facing `Negotiating Style` projection.

**AM-007** Dense cognitive state should not be duplicated into hidden Odoo fields merely to avoid a memory dependency.

**AM-008** Odoo may retain opaque ActorModel ref/revision metadata without depending on Graph Memory for startup correctness.

**AM-009** If Graph Memory is unavailable, reasoning degrades explicitly; missing ActorModel state is not fabricated.

**AM-010** Human-facing summaries are projections and must never be re-promoted as stronger evidence than their underlying model/observations.
