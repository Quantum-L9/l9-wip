# ADR-001: One action owner and Gate-only trusted collaboration

**Repository:** Quantum-L9/Constellation.Gate  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_OPERATOR_DECISION  
**Implementation/deployment:** not performed by this delivery.

## Context
Consumers can use nodes but cannot serve as trusted node dependencies; nodes collaborate only through Gate.

## Decision
Bind role/source/scope to authentication, route one semantic owner per action, and dispatch only to admitted nodes. Correlated client responses remain allowed.

## Alternatives not selected
Direct peer calls; consumer registration as node; action resolution in context/profile/client code.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
All six services share protocol but retain individual semantics, principals and failure domains.

## Required evidence
Wrong owner registration, client worker target, peer route and unsigned role spoof fail. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Remove only inactive new registrations; preserve in-flight operation reconciliation.

## Provenance
User corrected consumer invariant; Gate pinned routing policy. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
