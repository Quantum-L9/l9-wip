# Capability behavior

`communication.capabilities`: return verified modality/feature/receipt-level availability under the caller's scope. It does not expose provider secrets or claim roadmap features are ready.

`communication.send`: perform one admitted discrete text/email/message effect for an exact target and content commitment. Accepted, delivered and unknown are separate.

`communication.session.open`: create an authorized realtime or telecom session with exact participant constraints and a bounded composition. Session creation is an external effect with stable operation identity.

`communication.session.respond`: render an AgentOS-authored response or chunk under an active session, current turn fence and sequence. Never generate an independent semantic answer.

`communication.session.close`: request termination/cancellation and report its actual confirmation strength. It does not compensate past effects.

`communication.inspect`: inspect original operation/session receipts and supported provider outcome without resending.

`communication.perceive`: process a bounded authorized media reference/window and return uncertain observations with source coordinates. It does not grant permission to retain raw content or write memory.
