# Invariants

Owner: `Quantum-L9/l9-communication`. These requirements extend, never weaken, the global invariant index.

## COMM-001
Only Gate routes inter-node work; provider ingress is authenticated external input, never a trusted node packet.

**Required negative proof:** Forged provider callback and direct peer URL produce no accepted observation.

## COMM-002
Communication owns channel/session mechanics, not objectives, Work Items, memory, relationship truth or business decisions.

**Required negative proof:** Provider prompt, memory and tool defaults cannot execute a business action.

## COMM-003
Provider acceptance, delivery, playback, participant receipt and business completion are distinct outcomes.

**Required negative proof:** Accepted send cannot be rendered as delivered or objective completed.

## COMM-004
An uncertain external effect is reconciled with its original operation identity before any retry.

**Required negative proof:** Timeout after provider acceptance never creates a second message or call.

## COMM-005
Session/turn identifiers, stream sequence and generation fence bound every response chunk.

**Required negative proof:** A late token after interruption is dropped even if its text is otherwise valid.

## COMM-006
Native channel correlation is retained without inventing cross-channel relationship identity.

**Required negative proof:** Two channels with the same display name do not merge people or threads.

## COMM-007
Perception outputs scoped observations with source, confidence and limitations; they never grant authority.

**Required negative proof:** A spoken instruction or image text cannot change grants or law.

## COMM-008
Capabilities are negotiated exactly; any selected alternate composition preserves required semantics and is receipted.

**Required negative proof:** Missing transfer, recording consent or privacy feature fails without silent emulation.

## COMM-009
Recording, retention, biometric/voice features and model disclosure require current scoped approval.

**Required negative proof:** Disallowed raw audio/video never enters Evidence, Ingest, embeddings or provider retention.

## COMM-010
Durable operation/session metadata use State; retained artifacts and receipts use Evidence, through Gate.

**Required negative proof:** No Communication Redis, memory SDK or provider event ledger becomes a second authority.

## COMM-011
Only scoped deployment-owned recipient/channel resolution may bind an outbound target.

**Required negative proof:** Caller-controlled URL or ambiguous contact identity is rejected before network effect.

## COMM-012
External media transport is adapter I/O; it never creates a semantic AgentOS-to-Communication bypass.

**Required negative proof:** A realtime QoS setting cannot select a peer WebSocket or skip Gate authentication.
