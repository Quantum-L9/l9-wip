# ADR-001: Communication without a hidden agent

Status: design decision for implementation; not deployed.

## Decision
Communication owns transport, channel sessions, effect mechanics and bounded perception. It uses State/Evidence through Gate where persistence is required. It never hydrates memory, decides objectives or permits provider business tools.

## Alternatives rejected
Embedding an agent inside a media provider would duplicate AgentOS and obscure effect authority.

## Ownership and security
Public capability semantics belong to this repository. Gate owns routing and admitted sender role. AgentProfile can request only within current external grants. Provider credentials are confined to owning adapters; no peer URL or sibling database access.

## Consequences
Extra explicit admission and receipt contracts are required, but adding a provider does not redefine AgentOS or the public capability boundary. Shared transport, State, Evidence and Context machinery is reused rather than copied.

## Qualification
Native interruption, timeout-after-send, webhook spoofing, consent withdrawal, retained-evidence and provider capability tests.

## Rollback
Disable the capability registration or selected adapter; preserve original operation identities and receipts. Reconcile uncertain effects before retry. Never activate the donor's parallel writer or a different semantic family as an emergency fallback.
