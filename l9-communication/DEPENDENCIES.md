# Dependencies and private implementation stack

Mandatory L9 dependencies are Gate_SDK and Constellation.Gate. State owns durable operation/session metadata; Evidence owns retained receipts and media artifacts. AgentOS is a target only for admitted node manifestation observation delivery. Neither Memory nor Context is a direct communication cognition dependency.

Selected external options are Agora, ElevenLabs, Twilio and a native email API adapter. Pipecat is optional when a demonstrated self-hosted requirement justifies it. The recipient/account binding may use an existing authorized source capability; current owner discovery precedes implementation. All exact versions, entitlements and privacy controls are unresolved deployment admission evidence, not architecture blockers for the generic contracts.

Do not import l9-graphiti-memory, a Redis active-memory implementation or another node's service source. Contract packages may be consumed from their owners. Provider SDKs appear only in adapter modules. Providers may be replaced only under verified feature/receipt/consent equivalence, with no hidden fallback.
