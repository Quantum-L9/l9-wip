# ADR-001: Preserve memory public ownership while exposing reusable node surface

**Repository:** Quantum-L9/l9-graphiti-memory  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_EXISTING_OWNER  
**Implementation/deployment:** not performed by this delivery.

## Context
New AgentOS capabilities must consume existing memory semantics, not assume implementation-specific access.

## Decision
Publish only minimal public gaps demonstrated by wrapper probe; preserve source/consent/idempotency/lifecycle semantics and existing retrieval ownership.

## Alternatives not selected
Wrapper reaches private tables; new MemoryRecord family; projection compiler assumed live fan-out.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Owner tests remain release authority; wrapper parity is additional proof.

## Required evidence
Public facade against installed wheel preserves principal and receipt fields. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Keep compatible owner API and canonical records; reject stale caller assumptions explicitly.

## Provenance
Existing memory owner docs and code. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
