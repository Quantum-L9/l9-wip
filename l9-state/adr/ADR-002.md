# ADR-002: Mongo first adapter and provider-neutral event recovery

**Repository:** Quantum-L9/l9-state  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_FIRST_ATTEMPT_OPTION  
**Implementation/deployment:** not performed by this delivery.

## Context
Mongo fits structured agent state and change notification, but its provider details cannot define L9 contracts.

## Decision
Use a transaction-capable replica-set deployment with scoped indexes and fences. Canonical journal is authoritative; Change Streams are optional wakeup with retained-history fallback.

## Alternatives not selected
Expose BSON operators/collection names; use provider resume token as the only event cursor; require LangGraph serialization.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Replacement adapter must pass same revision, fencing, idempotency and recovery tests.

## Required evidence
Invalidate provider cursor, fail over primary and restart consumer; replay exact semantic events without duplicate effects. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Switch adapter only through controlled data migration and equivalence; not a runtime silent fallback.
