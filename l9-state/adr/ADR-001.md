# ADR-001: Opaque schema-bound state with one atomic mechanical commit

**Repository:** Quantum-L9/l9-state  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_BOUNDARY_WITH_PROPOSED_COMMIT_CONTRACT  
**Implementation/deployment:** not performed by this delivery.

## Context
All manifestations need state without moving domain meaning into infrastructure.

## Decision
State validates schema/authorization and commits payload revision, operation receipt, journal and outbox atomically. AgentOS/profile owns meaning.

## Alternatives not selected
State knows Work Item kinds; separate stores commit record and event independently; generic arbitrary DB query service.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
State owns transaction boundaries and idempotent receipt lookups. Domain policy remains outside the service.

## Required evidence
Two concurrent writers, crash boundaries, collision keys and unauthorized schema changes. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Recover using exact operation receipt; do not rebuild state from model narrative.

## Provenance
User State invariant; Mongo official atomicity/change-stream docs. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
