# ADR-002: One embedding executor per scoped representation view

**Repository:** Quantum-L9/l9-evidence  
**Date:** 2026-09-25  
**Status in pack:** PROPOSED_IMPLEMENTATION_OF_LOCKED_INVARIANT  
**Implementation/deployment:** not performed by this delivery.

## Context
Multiple transform and storage tools can otherwise embed the same text twice under incompatible spaces.

## Decision
A view manifest names executor, render/normalization/model revision/dimensions/space/scope. Ingest supplies representation or bounded embedding evidence; only Evidence owns the final index.

## Alternatives not selected
Both Ingest and Evidence silently embed; cross-tenant cache reuse; changing active model without versioned view.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Embeddings are rebuildable and never authoritative. Deletion covers vectors and caches.

## Required evidence
Model-space mismatch refusal, no-change reuse and erasure/replay conformance. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Route back to prior proved view only while its privacy/source validity remains intact.

## Provenance
Research on multiple vector views and existing memory projection contract. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
