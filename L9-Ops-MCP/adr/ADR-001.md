# ADR-001: Keep optional source authority, retire universal context/memory role

**Repository:** Quantum-L9/L9-Ops-MCP  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_DIRECTION  
**Implementation/deployment:** not performed by this delivery.

## Context
Ops-MCP is an example/source, not the target generic architecture.

## Decision
Preserve authenticated exact authored-source projection where it truly owns authority; consume shared Context/Memory and retire local generic substitutes.

## Alternatives not selected
Make Ops the mandatory universal context backend; keep alternate transport and direct graph admission.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Source capability remains swappable without agent runtime edits.

## Required evidence
Alternate source works with same Context contract; exact source digests retained. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Rollback safe source translation only, never unsafe provider/memory bypass.

## Provenance
Pinned Ops source observations and user source-example instruction. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
