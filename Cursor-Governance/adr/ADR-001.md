# ADR-001: Evict generic machinery, retain host truth and Program boundaries

**Repository:** Quantum-L9/Cursor-Governance  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_DIRECTION_WITH_SCOPED_MIGRATION  
**Implementation/deployment:** not performed by this delivery.

## Context
Reusable runtime components inside coding governance conflict with constellation ownership.

## Decision
Extract generic ingestion/context/autonomy to owner nodes/profile code. Preserve host capture/acceptance and Program Execution authority. Cut over with one writer and receipt parity.

## Alternatives not selected
Move whole autonomy directory blindly; leave shadow workers; manually maintain generated host output.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
Migration maps functions and invariants, not just directories. Host adapters remain thin.

## Required evidence
No generic runtime imports after retirement; host failure behavior remains explicit. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Before activation revert binding; after writes reconcile forward and never enable dual writers.

## Provenance
Cursor source index/thin-provider law and user eviction lock. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
