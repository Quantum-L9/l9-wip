# Cursor-Governance: behavioral delta

Evict generic runtime implementations and retain coding-host governance, universal-profile assets and thin host bindings only.

## Required proof obligations
1. Host results are captured and accepted before ingest without domain semantics in the transport adapter.
2. No direct Graphiti/database writes remain in coding-host paths.
3. No generic duplicate context/autonomy engine remains after cutover.
4. Interrupted handoff resumes with original source/effect identities.
5. Independent host startup/close and coding safety tests remain green.

## Cross-owner rule
A missing guarantee becomes a scoped upstream contract change with negative tests. It does not become a consumer-specific bridge, duplicated state owner or unchecked fallback. Test the actual installed package and Gate boundary where relevant, not just source imports.

## Evidence and release
Record tested base/head, dependency versions, schema digests, actual commands and outputs, refusal cases and explicit skipped/blocked checks. A source inspection finding is not a deployed-system claim.
