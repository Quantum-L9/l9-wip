# Gate_SDK: convergence invariants

- Second packet envelope or second HTTP stack.
- AgentProfile parser, State/Memory/Context domain models in SDK core.
- Peer URL APIs.
- Automatic retry of domain effects.
- Trust based only on a declared origin_kind.

- Latest operator architecture outranks donor implementation form, but does not authorize silent live data loss.
- Preserve one owner per behavior and one canonical transport.
- Consumers remain consumers until independently admitted as nodes.
- Existing external/domain authority is not transferred by moving files.
- Required unknowns stop dependent execution, not independent work.
