# ADR-001: One transport with credential-bound client/node distinction

**Repository:** Quantum-L9/Gate_SDK  
**Date:** 2026-09-25  
**Status in pack:** LOCKED_OPERATOR_DECISION  
**Implementation/deployment:** not performed by this delivery.

## Context
Observed application root builder uses node provenance; the new lock requires consumers not be treated as nodes.

## Decision
Reuse canonical transport and add the smallest compatible role binding coordinated with Gate; role declaration alone never grants trust.

## Alternatives not selected
Second client SDK transport; per-agent bridges; a profile flag selects privileged node identity.

## Ownership and invariants
The semantic owner is this repository only for the responsibility named above. Imported platform invariants retain their original owners. Read BOUNDARY.yaml and INVARIANTS.md before implementing. No adapter, registry index or profile may silently redefine this decision.

## Consequences
SDK remains domain-payload opaque. Server proof is mandatory; code observation alone is not a proven exploit.

## Required evidence
Client claiming node fails, true node succeeds, one deadline/send attempt retained. Unit-level negative tests, installed-artifact parity and staging proofs are required where applicable; pack checks cannot satisfy them.

## Migration and rollback
Version valid migration; do not restore role-confusion behavior for convenience.

## Provenance
Pinned Gate_SDK client.py and transport/provenance.py. This record preserves locked direction while detailed schema/implementation proposals remain subject to owner contract acceptance. It is not a retrospective assertion that code has been merged or deployed.
